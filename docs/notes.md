# 笔记待办（含提醒气泡、富文本编辑器）

从 CLAUDE.md 拆出来的细节：改这部分代码前先读。

## 实现

- `notes.go` + `src/notes.ts`：工具「笔记待办」（侧栏第二项），待办和笔记两个标签页（记在 localStorage `notes-view`）。数据存在 `%APPDATA%\Toolbox\notes.json`，每次修改把全部数据经 `notesChanged` 只发给主窗口（`Notes.main`，`Event.Emit`），响铃的待办经 `todoAlertsChanged` 广播给悬浮球和气泡（它们用不着笔记正文）。待办的 `due` 是本地时间字符串 `2026-11-12` 或 `2026-11-12T15:00`（就是页面 date/time 输入框的格式），按「已逾期 / 今天 / 以后 / 没有日期」分组，组内先重要、再按时间；已完成默认折起。快速添加用 `parseQuick` 从文字里取出时间（今天/明天/后天/今晚/明早、周X/下周X、M月D日、15:00、下午3点半；不带上午的 1–6 点算下午；今晚/明晚后面的钟点算晚上、明早算早上，晚上12点是第二天 00:00；2月30日这种不存在的日期不认；每天/工作日/每周X/每月N号/每年M月D日 设成重复），单测见下面。重复（`repeat`：day/weekday/week/month/year，必须有日期）：勾完成不标记已完成，而是 `nextRepeat` 推到下一次（每月 31 号遇到小月取月底）；没完成的由 `remind` 用 `repeatLatest` 在下一次时间到时自动推过去并再响；新建或改了时间时 `repeatAfter` 把已过的时间推到下一次；重复待办的「稍后」写 `snooze`、不改 `due`，以免把之后每次的时间也带偏。子项（`subs`，2026-11-14 加）：和这条待办是一个整体，默认展开在卡片里，勾选框和 ✕ 和待办行一样，进度胶囊点一下收起（`folded`）；最后一个子项勾完整条自动完成（toast 可撤销），整条勾完成时子项全部勾上，重复待办完成后子项清空勾选；「＋子项」/「＋ 添加子项」打开输入框，回车加一个并留在框里，Esc 结束；编辑框里也能增删改。图片（`images`，notefile 地址，最多 20 张，2026-11-14 加）：添加框旁的图片按钮、在添加框/编辑框里粘贴截图、或把图片文件拖进窗口（编辑框开着时进编辑框，否则进添加框），卡片下方一排缩略图，点开用 `ui.ts` 的 `lightbox`（从 `blocks/util.ts` 搬过来，免得笔记页入口带上 TipTap；在模态对话框里时放进对话框，Esc 只关大图）；`cleanFiles` 也算待办引用的图片。CDP 测试 `.dev/js/todo-images.js`（测完 `todo-images-clean.js`）。Go 单测 `notes_test.go`。带时间的待办由 `Notes.watch` 每 15 秒检查一次，到点设 `alert`（响铃）并弹系统通知（ID `todo-<id>`）。**用户电脑关了系统通知总开关**（`HKCU\...\PushNotifications\ToastEnabled=0`，MyGo 在 Windows 用托盘气泡，也被关掉），所以主要靠 `reminder.go` 的提醒气泡：透明置顶小窗口 `/?bubble`（`src/bubble.ts`），贴在悬浮球旁边有空的一侧（球隐藏时在右下角），页面按卡片高度调 `Reminder.Resize`；每条可「完成 / 10 分钟后 / 1 小时后（`Notes.Snooze`）/ 知道了（`Notes.Dismiss`）」，✕ 只收起（`Reminder.Collapse`），新响铃会再展开；显示满设置里的分钟数（`settings.reminder.autoHide`，默认 3，0 不收起）自动收起，人不在电脑前也只留红点。提示音（`settings.reminder.sound`，`ui.ts` 的 `chime`，设置页可试听）。响铃期间悬浮球有红色数字角标、摇摆，不缩进边缘（`Widget.setAlert`），单击球调 `Reminder.Open` 直接打开待办。`reminded` 防重复；改时间或稍后会重新提醒，超过一天没提醒的（期间程序没开）只标记不响。编辑框的时间是文本框 24 小时制（`parseTime` 认 9、930、9:5、21点），带常用时间按钮。笔记是富文本（HTML 存在 `body`，旧的纯文本笔记用 `noteHTML` 按行转段落），编辑器在 `src/editor.ts`（`notes.ts` 用 `import("./editor")` 在第一次显示笔记时才加载：它连同 TipTap、KaTeX 占页面代码的九成，悬浮球、气泡、悬浮窗和工具箱启动都用不着；所以 `notes.ts` 只能 `import type`，标题/搜索用的 `noteText` 放在 `notes.ts`）：TipTap 2.27.3（全部 `@tiptap/*` 要同一版本，否则构建报 MISSING_EXPORT），仿 Outline——第一段当标题、Markdown 输入规则、`/` 菜单（`@tiptap/suggestion`，AI 续写/让 AI 写、H1–H4、任务/无序/有序列表、引用、代码块、分割线、提示/成功/警告 callout、当前日期时间，拼音首字母过滤，快捷键同 Outline：Ctrl+Shift+1–4/7/8/9）、选中文字的工具栏（自己定位，粗斜删高亮代码、H1–3 引用、三种列表、链接、✨ AI 菜单）、AI 写作面板（浮在编辑区底部，流式显示，重试/替换选中/插入下方）；Ctrl+点击链接用 `Notes.OpenURL` 在浏览器打开。Outline 那些块都在 `src/blocks/`（自绘的 node view，数据放在节点属性里，`renderHTML` 输出带 `data-*` 的元素以便存成 HTML）：`media.ts` 图片（拖右边缘调宽度、说明、双击放大）、视频、附件（打开/所在位置）、画册；`table.ts` 表格和光标在表格里时的表格工具栏；`source.ts` 数学块（KaTeX）、行内公式（输入 `$…$`）；画板（Excalidraw）、Mermaid 和中文手写字体加过又按用户要求去掉了（2026-11-12，exe 从 35MB 回到 13MB）；`layout.ts` 两栏/三栏、分页符、嵌入（哔哩哔哩/YouTube/腾讯视频/优酷/网易云/Figma 等转播放器地址，其他网址直接 iframe，粘贴这类链接到空行自动嵌入；只嵌 http/https 且不是本应用自己的地址，iframe 带 `sandbox`，不能把整个窗口带走）；`smart.ts` 看板/日历/投票/打卡/加密文本（PBKDF2+AES-GCM，页面是 secure context）。图片、视频、附件的文件存在 `%APPDATA%\Toolbox\notes-files`（`notefiles.go`，`mygo.Protocol` 注册 `notefile` scheme，WebView2 上地址是 `http://notefile.localhost/<名字>`，笔记里存这个地址），粘贴截图走 `Notes.SaveFile`，拖进窗口走 `Notes.ImportFiles`，`/图片` 等走 `Notes.PickFiles`；没有笔记引用、且超过一天的文件由 `cleanFiles` 删掉。插入块要用 `blocks/util.ts` 的 `insertBlocks`（否则插入后块处于选中状态，下一次插入会把它替换掉），`TrailingParagraph` 保证文末总有空行；数学块只在从 / 菜单刚插入时自动打开编辑（`justInserted`），重新打开笔记不会。打开着的笔记不再拿广播回来的内容覆盖编辑器（旧的保存晚到会把新内容冲掉）输入停 400ms 自动保存；页面在自己保存期间（`saveTimer`）或编辑器有焦点时不拿广播覆盖内容。新建后什么都没写的笔记，切到别的笔记或下次打开时会删掉。删除有「撤销」toast（重新添加，会换 ID）。悬浮球菜单「记一条待办」打开这里并聚焦输入框

## 调试

- `.dev/js/notes-ui.js`：笔记待办的 CDP 测试（快速添加解析、分组、勾选、编辑、删除撤销、到点提醒标记、笔记自动保存/置顶/搜索），测完删掉新增的数据。`notes-sample.js` 加截图用的样例数据，`notes-clean.js` 删掉
- `.dev/js/editor-ui.js`：笔记编辑器的 CDP 测试（`/` 菜单、callout、选中工具栏、AI 菜单、保存为 HTML），`editor-clean.js` 删掉测试笔记。编辑器实例在 `.ProseMirror` 元素的 `editor` 属性上；`commands.insertContent` 不触发 Markdown 输入规则，要模拟打字用 `view.someProp("handleTextInput", …)`
- `.dev/js/blocks-ui.js`：各种块的 CDP 测试（图片文件、表格及工具栏、公式、分栏、嵌入、看板/投票/打卡、加密解密、顶层块顺序），测完用 `editor-clean.js` 删测试笔记
- `.dev/js/repeat-ui.js`：重复待办的 CDP 测试（快速添加「每天」、🔁、编辑框重复、到点响铃，约 1 分钟、稍后不改 `due`、完成推到明天），测完删掉
