# 截图翻译、长截图

从 CLAUDE.md 拆出来的细节：改这部分代码前先读。

## 实现

- `shot.go` + `shot_windows.go` + `translate.go` + `src/shot.ts`：工具「截图翻译」（2026-11-13 加）。`Shot.start(mode)`：用 GDI `BitBlt`（带 `CAPTUREBLT`，悬浮球这类分层窗口也截进去）按 `mygo.Display.ID`（就是 HMONITOR）截每块显示器的物理像素，存成 BMP（不用编码，最快）经 `shot` scheme（`http://shot.localhost/frame/<显示器>-<序号>.bmp`）给每块显示器一个置顶全屏选区窗口 `/?shot=<显示器 ID>`；窗口第一次创建后一直留着（隐藏），下次只广播 `shotCaptured`，页面 `Shot.Frame` 取图、解码后调 `Shot.Ready` 才显示，光标所在那块拿焦点。从工具页按钮开始时先把工具箱窗口藏起来、结束后再显示（`restore`）。选区页面：拖选、拖边角调整、拖中间移动，遮罩用 `clip-path: polygon(evenodd…)` 挖洞（超大 `box-shadow` 不可靠），坐标按 `frame.width / innerWidth` 换成物理像素交给 `Shot.Finish(显示器, 矩形, 动作, 标注层)`；标注和长截图（2026-11-13 加，仿微信）：矩形/椭圆/箭头/画笔/马赛克/文字，粗细三档、六种颜色（记在 localStorage `shot-mark`），Shift 正方形/圆/45°，Ctrl+Z 撤销，有标注后点选区外不会重新框选。标注存成页面坐标的对象，`paintMarks` 画在全屏 canvas 上（裁到选区），完成时按选区物理像素再画一遍成透明 PNG（base64）给 Go 用 `draw.Over` 盖到截图上；马赛克是截图缩小再放大的粗块图，经画笔笔迹的蒙版露出来，永远在其他标注下面。canvas 要读回截图像素，所以 `shot` scheme 带 `Access-Control-Allow-Origin: *`、`<img crossorigin>`，否则 canvas 被污染导不出。copy（PNG 写剪贴板，MyGo 会转 DIB；资源管理器只粘贴文件，所以截图页「复制时附带图片文件」（`settings.shot.copyFile`，默认关）开着时 `copyPNG` 另把图写成 `%TEMP%\Toolbox\shots\截图 日期 时间.png`（超过一天的删掉）一起放进剪贴板，剪贴板历史见到只有这一个文件且带 PNG 时照样记成图片（`isShotFile`）；贴图和图片编辑的复制也走它（`copyPNG` 是包级函数，传 `*Settings`）；临时文件在每次复制和启动时（`cleanShotFiles`）清理）/ save（另存对话框，记住上次的文件夹 `settings.shot.saveDir`）/ pin / ocr / translate；出错时选区窗口已经没了，所以用 `mygo.Dialog.Error` 提示。mode 为 ocr/translate/edit 时松开鼠标就直接执行；标注的类型、颜色、粗细和 `paintMarks` 在 `src/marks.ts`，和图片编辑共用。贴图窗口 `/?pin=<id>`：透明无边框置顶，留 `pinPad` 的边画阴影，`Shot.ResizePin` 按缩放和文字面板改大小（从左上角长，超出工作区就往回挪），拖动同悬浮窗（`DragPin` 在 Go 里跟鼠标），滚轮缩放、双击/Esc 关闭、右键原生菜单（识别文字/翻译经 `pinAction` 事件交给页面）。OCR 是 Windows 自带的 `Windows.Media.Ocr`，Go 直接调 WinRT（`comObj` 按 vtable 序号调用，序号用 `.dev/winrt-dump.ps1` 从系统元数据核对；SoftwareBitmap 用 `LockBuffer` + `IMemoryBufferByteAccess` 写像素，buffer 和 reference 要 `IClosable.Close` 后才能识别；异步用轮询 `IAsyncInfo.Status`），在一个锁定的 MTA 线程上跑；小图放大一倍再认；中文识别器把每个字、每个数字当一个词，`joinWords` 按整行字高中位数和间距决定加不加空格，中文标点前后不加；识别结果主要是字母而当前识别器是中文（或反过来）且系统装了另一种语言时自动换识别器重认（这台电脑原先只装了 zh-Hans-CN 的 OCR，英文被认成「foxJumps ]azy translatlon」；2026-11-13 装了 en-US，`TestOCREnglish` + `testdata/ocr-en.png` 回归）。每行带背景色/文字色（`lineColors`：框外一圈取平均当背景，框内离背景最远的像素当文字色），翻译时页面按行把译文盖在原图上（`.pn-line`，字号按行高缩到放得下），可切原图/译文。翻译引擎 `settings.shot.engine`：auto（默认，谷歌 `translate.googleapis.com` gtx 接口，失败换必应——从 `bing.com/translator` 页面读 IG/IID/key/token 再调 `ttranslatev3`，国内会跳到 cn.bing.com）/ google / bing / ai（用 `settings.shot.ai`——和 AI 写作分开配置，在设置页「AI 翻译」（AI 写作下面），可一键复制写作的配置，截图翻译页的引擎说明里有「去设置」；表单是 `settings.ts` 的 `aiFields`/`bindAIFields`，两处共用；要求按 JSON 数组逐行返回；用户的 freeapi 网关 `auto` 模型要两分钟，所以默认不用）。机器翻译把各行用换行连起来一次翻，结果行数对得上才盖图，否则只给文字。Edge 内置翻译的 `edge.microsoft.com/translate/auth` 已经 404，别再用。`settings.shot.to`：auto（中文译英文，其他译中文）/ zh / en。单测：`shot_windows_test.go`（`testdata/ocr-zh.png` 识别回归）、`translate_test.go`（`TOOLBOX_LIVE=1` 才真的请求谷歌和必应）
- `scrollshot.go` + `stitch.go`：长截图（选区工具栏的按钮）。`Shot.Scroll` 收起选区窗口，在区域外圈放一个透明、鼠标穿透（`SetIgnoreMouseEvents`）、不进截屏（`SetContentProtection` = `WDA_EXCLUDEFROMCAPTURE`）的边框窗口 `/?longframe`，旁边放面板 `/?scroll`（也不进截屏，放不下就放在区域角上）。`scrollLoop` 每 70ms 用 `captureScreen` 截区域交给 `stitcher.add`：每行算 64 段平均亮度的签名（去掉右边 24px 滚动条），顶部、底部不变的行当固定栏（只保留一次，底栏最后补上），在中间带里找让新图第 i 行 = 旧图第 i+d 行的 d（容差、纯色行不计分、重复内容取离上次 d 最近的），往上滚或一次滚超过一屏返回 lost 并提示往回滚。「自动滚动」把鼠标放到区域中央、`SendInput` 发滚轮，鼠标移出区域就暂停，2 秒没变化算到底。预览按整数倍缩小、body 部分增量缓存，经 `shot.localhost/scroll/<seq>.bmp` 给面板。`ScrollEnd(copy/save/pin/"")` 结束；贴图页会把长图缩到放得下屏幕。最长 30000 像素，且总像素不超过 3000 万（`maxStitchPixels`，宽选区每行更占内存），到了就不再往上加。截图结束时 `end` 广播 `shotEnded`，藏起来的选区页放掉整屏图片和画布；5 秒后 `debug.FreeOSMemory`（`freeSoon`，Go 进程从 170MB 回到 55MB）。单测 `stitch_test.go`（固定头尾、滚动条、太快、往回滚，逐像素比对）

## 调试

- `.dev/js/shot-select.js`：在选区窗口里合成拖选并点工具栏按钮。表达式不能带参数，用 `sed 's/\[RECT_AND_ACTION\]/[x, y, w, h, "pin"]/' .dev/js/shot-select.js > .dev/js/tmp-sel.js` 生成再跑（页面 CSS 像素；动作留空则只选不点）；先用 `hotmsg.ps1` 发 5（截图）或 6（截图翻译）把选区窗口调出来。选区窗口会盖住用户整个屏幕，测完马上点掉
- `.dev/js/shot-marks.js`：在选区里画各种标注后贴图（`hotmsg.ps1` 发 5 先调出选区窗口，再 `--shot … pin` 看合成结果，测完关贴图）。`shot-ai.js`：截图翻译页的「翻译用的 AI」（只在 AI 引擎显示、复制写作配置、两套互不影响），测完还原
- 长截图实测：`top.ps1`（任务 `ToolboxTop`，`.dev/top.txt` 写 on/off）把主窗口临时置顶（否则截到的是挡在前面的别的窗口），然后 `long-prep.js`（主页面）→ `hotmsg` 5 → `long-select.js`（shot 页）→ `long-scroll.js`（主页面）→ `mygo.call("Shot.ScrollState")` 看高度，`Shot.ScrollEnd` 结束，最后 top.txt 写 off 再跑一次。`cdp.mjs` 的 url 片段是子串匹配，所以边框页叫 `?longframe` 而不是 `?scrollframe`
- 英文 OCR：`Add-WindowsCapability -Online -Name Language.OCR~~~en-US~0.0.1.0` 经 SSH 跑报「拒绝访问」，要用 SYSTEM 计划任务跑（装完已删掉任务；Windows Update 下载要二三十分钟）
