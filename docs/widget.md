# 悬浮球（桌宠）、和桌宠聊天

从 CLAUDE.md 拆出来的细节：改这部分代码前先读。

## 实现

- `widget.go` + `src/widget.ts`：悬浮球（桌宠式）。透明、无边框、置顶、不进任务栏的小窗口，页面是 `/?widget`（`main.ts` 按查询参数分流）。必须给 `MinWidth/MaxWidth`，否则 Windows 把窗口撑到至少约 136 宽。单击 `Widget.Open`；右键 `Widget.Menu` 每次按当前状态新建原生菜单；拖动由页面在移动超过 4px 后调 `Widget.Drag`，Go 每 10ms 读 `Screen.CursorScreenPoint` 移窗口直到 `GetAsyncKeyState` 显示左键松开，再夹回工作区，开了「贴边吸附」（`widget.snap`，默认开）时靠近左右边缘 32px 内贴边，位置存进设置（`Save` 不会覆盖位置）。贴边且开了「缩进去一半」（`widget.tuck`）时，`apply` 把球放到半个身子在屏幕外（`edgeOf` 判断贴的是哪条边，旁边还有显示器的边不缩），页面 `pointerenter/leave` 调 `Widget.Peek`，移上去滑出、移开 250ms 后滑回（用户嫌 600ms 慢）；拖动和右键菜单期间不缩。拖文件到球上加进快捷启动；断开物理屏时右下角显示绿点；待办响铃时右上角红色数字角标（球的图片用 `clip-path` 裁圆，角标才能露出圆外）。形象（2026-11-17 加，`settings.widget.pet`）：`ball`（原来的球）/ `cat` `ghost` `slime` `bot`（`src/pets.ts` 画的 100×100 SVG 原创角色）/ `custom`（可以有多张，最多 20：`Settings.PickPetImage` 把图片复制进 appearance 文件夹叫 `pet-<时间>.<扩展名>` 并加进 `widget.images`，`RemovePetImage` 删掉；`widget.image` 是正在用的那张，`Save` 不改 `images`、只接受其中的 `image`；`normalizePetImages` 把旧版单张的 `image` 并进列表；`cleanAppearance` 保留背景图和列表里的图）。心情写在球的 `data-mood`（idle/happy 鼠标在上面/alert 有响铃或掉线/drag 拖动中/sleep `Widget.Idle`=系统空闲超过 5 分钟），角色的部件用 `data-m="…"` 列出在哪些心情里显示，动画全在 `src/css/pets.css`；单击、偶尔自己跳一下/歪头是 `.w-look` 上的 `p-act-*`。一直循环的动画（呼吸、眨眼、尾巴、指示灯、zzz、响铃摇摆）只在球上有 `.w-live` 时播：鼠标在上面、拖动中一直有，换心情和每隔 12–30 秒 `fidget` 时给 `livelyFor`（4 秒），睡着时没有（2026-11-18：透明置顶窗口每帧都要重新合成，一直动时 GPU 进程加悬浮球页面占一个核约 18%，改后空闲约 5%，睡着近 0；新加循环动画的部件要加进 pets.css 那条 `.w-ball:not(.w-live) :is(...)`）。大小上限 160（`maxWidgetSize`）。长按（500ms 不动）打开聊天，见下面 `petchat.go`
- `petchat.go` + `src/petchat.ts`：和桌宠聊天（2026-11-17 加）。长按悬浮球或右键菜单「和我聊天」→ `PetChat.Open`：不透明无边框小窗 `/?petchat`（不置顶：点到别的窗口它就退到后面，不挡东西，再长按又出来）（380×520，同剪贴板小窗用 `BackgroundColor`、`forceFocus`），放在球旁边有空的一侧、底边对齐球；✕/Esc/Alt+F4 只隐藏（看 `appQuitting`），标题栏拖动（`PetChat.Drag`）。显示、拖动、隐藏后调 `onMove` → `reminder.place()`，提醒气泡用 `clearOf` 躲开聊天窗（先放到它上面，再下面，再旁边）。回答用设置里「AI 写作」的配置：`AI.Chat`（`ai.go`，和 `AI.Write` 共用 `start`，经 `aiChunk` 流式推送，`AI.Cancel` 停止），系统提示按 `petPersonas` 让 AI 以当前角色说话，只发最后 30 轮。聊天记录存在 localStorage `pet-chat`（最多 60 条，出错的不存），回复用页面里的小 `markdown`（代码块、行内代码、粗体、标题、列表、http 链接经 `Notes.OpenURL` 打开，其余都转义）；没配 AI 时错误气泡带「去设置」（`PetChat.OpenSettings`）
