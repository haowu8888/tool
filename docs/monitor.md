# 系统监控、端口占用、监控悬浮窗

从 CLAUDE.md 拆出来的细节：改这部分代码前先读。

## 实现

- `monitor.go` + `monitor_windows.go` + `src/monitor.ts`：工具「系统监控」。只在有人看时采样（`Monitor.Watch(who, on)`：页面可见时 `page`、悬浮窗显示时 `overlay`；Windows 上窗口藏到托盘后页面的 `visibilityState` 仍是 visible，所以 `main.go` 用 `win.OnHide/OnMinimize/OnShow/OnRestore` 调 `Monitor.setHidden`，藏着时 `page` 不算数），按 `settings.monitor.interval` 广播 `monitorSampled`。全部不用管理员：PDH 计数器（`% Processor Utility` 同任务管理器、`% Processor Performance`×`Processor Frequency` 算当前频率、每个逻辑核、`GPU Engine` 按引擎类型求和取最大同任务管理器、GPU 显存、`Network Interface` 只算物理网卡——VMware/Tailscale/代理隧道等用 `virtualAdapter` 正则排除以免重复、`PhysicalDisk` 读写），`GlobalMemoryStatusEx`、各固定盘空间、电池（SetupAPI 找电池设备 + `IOCTL_BATTERY_QUERY_*`：电量、功率、健康、循环次数）、进程（Toolhelp + `GetProcessTimes`，按程序名合并取前 8，可结束）、硬盘温度（`IOCTL_STORAGE_QUERY_PROPERTY` 的 `StorageDeviceTemperatureProperty`=52，打开 PhysicalDrive 不要访问权限，不用管理员）。**CPU 温度 Windows 没有接口**（ACPI 热区在这台华为本上恒为 28°C，Intel IGCL 初始化失败），已于 2026-11-12 给用户装好 LibreHardwareMonitor 0.9.6（`D:\application\LibreHardwareMonitor`，PawnIO 2.2 驱动 `-install -silent` 静默装；配置文件写了托盘最小化 + 网页服务器只听 `127.0.0.1:8085`——它的 HttpListener 按 Host 匹配，所以地址必须写 127.0.0.1 不能写 localhost；开机由计划任务 `LibreHardwareMonitor` 以最高权限在登录 30 秒后启动；读不到风扇：华为的风扇由嵌入式控制器 + Intel DTT 风扇参与者 `TFN1` 管，LibreHardwareMonitor 不支持，`\_TZ.FAN0-4` 这 5 个 ACPI 风扇设备只有开/关电源状态且空闲时全是 D3，不能当转速用；Iris Xe 核显没有独立温度传感器，只读它的功率和频率；所以加了「风扇估计转速」：`monitor.ts` 的 `feedFan/fanGuess` 按 CPU 最近 10 秒平均温度和功耗分 高速（≥80°C 或 ≥35W）/中速（≥68°C 或 ≥20W）/安静，页面温度区第一行和悬浮窗 `fan` 项显示，并写明是估计），`lhmReader` 读 `settings.monitor.sensorsUrl/data.json`（跳过 `Distance to TjMax`；页面把各核温度合成一行小标签，CPU 行名字译成 封装/最热的核心/核心平均）（树：root→计算机→硬件(深度 2)→传感器类别→传感器，`monitor_test.go` 有样例）。系统信息用一次 PowerShell CIM 查询（约 5 秒，缓存，页面可刷新/复制）。页面：6 张卡片带最近一分钟折线、各核柱、温度（按 `tempWarn` 变黄/红）、磁盘空间、占用最多的程序、系统信息。每次采样不整块 `innerHTML` 重建，而是 `patch(box, html)` 只改变化的属性和文字（元素还是原来那个，悬停、提示、点击不会丢），所以这里的按钮不能每次绑监听：「结束」由 `.m-procs` 代理点击、按 `drawnProcs` 的序号找程序；鼠标按下期间不重画（`pressing`），免得按下和松开之间那一行换成别的程序
- `ports.go` + `ports_windows.go`：系统监控页下方「端口占用」（2026-11-15 加）。`GetExtendedTcpTable`/`GetExtendedUdpTable`（OWNER_PID，不用管理员）列监听的 TCP 和绑定的 UDP，「全部连接」再加每条 TCP 连接；`::`/`::1` 按 0.0.0.0/127.0.0.1 合并，免得双栈监听列两行。列表在自己的框里滚动（最高 360px），右上「收起」后不再刷新（记在 localStorage `ports-folded`，收起时只在进页面时读一次算个数）；页面每 5 秒刷新，可按端口/PID/程序名筛选，复制 PID、打开程序位置（服务的路径读不到）、结束进程。单测 `ports_windows_test.go`
- `overlay.go` + `src/overlay.ts`：监控悬浮窗 `/?overlay`，透明置顶小条，显示 `settings.monitor.overlay.items` 选的项，按内容调 `Overlay.Resize`（透明窗口变宽时新露出的那条会先黑一下，所以各数值按 `widths` 留固定 `min-width`，窗口只变大、换显示项或横竖排才重新量；`Resize` 把窗口夹回工作区，没拖过时留在右上角）；拖动同悬浮球（`Overlay.Drag`，位置存设置、`Save` 不覆盖）、双击打开系统监控、右键原生菜单（竖排、鼠标穿透 `SetIgnoreMouseEvents`、隐藏）。全局快捷键 `Ctrl+Alt+M`（action `overlay`）、托盘和悬浮球菜单都能显示/隐藏
